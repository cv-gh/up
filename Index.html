Opt-in dist-tag permissions for npm trusted publishing

2026-09-30

npm trusted publishing configurations can now be granted opt-in permission to manage dist-tags using short-lived OIDC credentials instead of long-lived tokens. The permission is off by default for new and existing configurations.
