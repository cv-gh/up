Tech Updates

A running digest of recent product and news updates from Azure, the GitHub Changelog, and OpenAI News.

Azure Updates

  • Generally Available: User-bound user delegation SAS for Azure Storage (2026-09-09 22:30 UTC) — Azure Storage now supports user-bound user delegation SAS, combining the flexibility of delegation SAS with Entra ID user-bound access for enhanced secure authentication. Now generally available.
  • Generally Available: Azure Ephemeral OS Disk with full caching for VM/VMSS (2026-09-09 21:24 UTC) — Ephemeral OS Disk with full caching is now generally available for new virtual machines and Virtual Machine Scale Sets, caching the complete OS image on local storage to eliminate remote-storage reads after caching finishes.

GitHub Changelog

  • CodeQL 2.27.0 adds support for Linux ARM64 (2026-09-09 21:45 UTC) — CodeQL 2.27.0 now runs natively on Linux ARM64, adds a new Rust security query, expands Java/Kotlin and C# framework coverage, and improves analysis accuracy across multiple languages.
  • Enterprise managed permissions for GitHub Copilot agent operations (2026-09-09 20:08 UTC) — Copilot Business and Enterprise admins can now centrally control which agent operations are blocked, require human approval, or proceed automatically, covering shell commands, file access, and network domains.
  • GitHub Advanced Security expands trial availability (2026-09-09 17:33 UTC) — Self-serve GitHub Advanced Security trials are now available to enterprises with up to 300 licenses (up from 100), letting more customers evaluate Code Security and Secret Protection.
  • Block pull requests with exposed secrets from merging (2026-09-09 17:14 UTC) — A new repository ruleset rule can block pull requests from merging when they introduce secret scanning alerts, adding a layer of protection beyond push protection.
